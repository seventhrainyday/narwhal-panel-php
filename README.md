# 🦈 独角鲸控制面板 · PHP 版 (Narwhal Cloud Panel for PHP)

根据 https://api.fuckip.me/openapi.yaml （Narwhal Cloud V2.0 API）搭建的网页控制面板。
**只需填写 API 密钥即可使用全部功能。**

这是 PHP 实现版本（另有 [Python 版](../narwhal-panel)），两者前端完全一致，
区别仅在于服务端语言：本版用 PHP 内置 Web 服务器 + cURL 做 API 反向代理。

## 快速开始

需要 PHP 7.4+（建议 8.x），并启用 `curl` 扩展（无 curl 时会自动降级为 stream 方式）。

```bash
./start.sh            # 默认监听 127.0.0.1:8080
./start.sh 9000       # 自定义端口
# 或直接：
php -S 127.0.0.1:8080 router.php
```

然后浏览器打开 **http://127.0.0.1:8080**，在右上角粘贴 API 密钥（`rnm_` 开头，
在独角鲸官网 → 个人资料页生成），点「保存并连接」即可。

- 密钥只保存在浏览器 localStorage，不上传到任何第三方。
- 零第三方依赖：只用 PHP 内置服务器 + curl/stream。

## 为什么需要本地服务？

浏览器直接跨域调用 `api.fuckip.me` 会被 CORS 策略拦截。
`router.php` 在同源下提供 `/api/*` 反向代理，把请求原样转发到
`https://api.fuckip.me/api/v1/*`（含 Authorization 头），
前端页面与代理同源，因此不受跨域限制。

可用环境变量覆盖上游地址（仅联调用）：
```bash
NARWHAL_UPSTREAM=http://127.0.0.1:18082 php -S 127.0.0.1:8080 router.php
```

## 文件说明

- `router.php` — PHP 内置服务器路由：静态文件服务 + `/api/*` 反向代理
- `start.sh` — 一键启动脚本
- `public/index.html` — 前端单页应用（与 Python 版共用同一套）

## 安全提示

- API 密钥等同于账号密码，请勿分享面板地址给他人（服务默认只监听 127.0.0.1）。
- 在「设置 → API 密钥管理」中可随时轮换/删除密钥。
